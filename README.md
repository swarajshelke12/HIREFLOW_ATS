## ⚡ The Vision

<br>

<table>
<tr>
<td width="600">

> *"The best hire you'll ever make is the one you almost missed."*

<br>

**HireFlow** is not another applicant tracking system.

It is an **AI-native recruitment intelligence platform** that fundamentally reimagines how organizations discover, evaluate, and connect with talent.

Traditional ATS systems are digital filing cabinets — they store resumes and sort keywords. HireFlow is different. It **reads between the lines**. It understands **transferable skills**, evaluates **potential over pedigree**, and communicates with candidates like a **thoughtful human**, not a cold machine.

Built with a cinematic **3D interactive portal**, powered by **dual-LLM orchestration**, and automated through **intelligent workflow pipelines** — HireFlow transforms the 23-hour screening process into a **23-second** one.

**Without sacrificing empathy. Without losing nuance. Without bias.**

</td>
</tr>
</table>

### 🌐 Candidate Arrives

The candidate lands on a **3D interactive portal** — not a boring form. Spline renders a living, breathing environment. They enter their details and drag-and-drop their resume.

</td>
</tr>

Form data + resume file are packaged into a **multipart FormData** payload and transmitted to a private n8n webhook endpoint over HTTPS. No data touches third-party servers.

</td>
</tr>

<tr><td colspan="2"><br></td></tr>

<tr>
<td width="80" align="center">

 │ 3 │
 └───┘

</td>
<td>

### 🔀 Intelligent Router

The n8n workflow **detects the file type** and routes accordingly — PDFs take the native extraction pathway, while images are routed through the **OCR Vision Agent** powered by Gemini.

</td>
</tr>

<tr><td colspan="2"><br></td></tr>

<tr>
<td width="80" align="center">

```
 ┌───┐
 │ 4 │
 └───┘
```

</td>
<td>

### 🧠 Dual-LLM Analysis

The extracted text is evaluated against a meticulously crafted **"Talent Scout" system prompt**. The AI doesn't just scan for keywords — it assesses **transferable skills, growth trajectory, domain fit, and latent potential** to generate a holistic 0-100 score.

</td>
</tr>

<tr><td colspan="2"><br></td></tr>

<tr>
<td width="80" align="center">

```
 ┌───┐
 │ 5 │
 └───┘
```

</td>
<td>

### ⚖️ Decision Engine

The score triggers deterministic actions:

| Score | Action | Status |
|:---:|:---|:---:|
| `> 80` | Marked for interview — fast-tracked | 🟢 |
| `45 - 80` | Held for manual HR review | 🟡 |
| `< 45` | Constructive rejection email drafted | 🔴 |

</td>
</tr>

<tr><td colspan="2"><br></td></tr>

<tr>
<td width="80" align="center">

```
 ┌───┐
 │ 6 │
 └───┘
```

</td>
<td>

### ✅ Human Gate & Output

All data is persisted to **Google Sheets** in real-time. Rejection emails enter an **approval queue** — no email is sent without explicit HR sign-off. The human always has the final word.

</td>
</tr>

### Installation

```bash
# ── Clone the repository ──────────────────────────────────────────────
git clone https://github.com/swarajshelke12/HIREFLOW_ATS.git

# ── Navigate into the project ─────────────────────────────────────────
cd HIREFLOW_ATS

# ── Install dependencies ──────────────────────────────────────────────
npm install
```

### Launch

```bash
# ── Start the development server ──────────────────────────────────────
npm run dev

# ── Open in your browser ─────────────────────────────────────────────
# → http://localhost:3000
```

### Build for Production

```bash
# ── Create optimized production build ─────────────────────────────────
npm run build

# ── Start production server ───────────────────────────────────────────
npm start
```

## 🔬 Deep Dive — Key Systems

<br>

</div>

<details>
<summary><b>&nbsp;🧠&nbsp; The AI Scoring Algorithm</b></summary>

<br>

The scoring engine doesn't use simple keyword matching. It employs a **multi-dimensional evaluation framework**:

```
┌─────────────────────────────────────────────────────────┐
│                   SCORING DIMENSIONS                     │
├──────────────────────┬──────────────────────────────────┤
│  Technical Fit       │  Domain-specific skill alignment │
│  Transferable Skills │  Cross-industry capabilities     │
│  Growth Potential    │  Learning trajectory signals     │
│  Communication       │  Resume clarity and structure    │
│  Culture Indicators  │  Values and work-style alignment │
└──────────────────────┴──────────────────────────────────┘
```

The **"Talent Scout" system prompt** instructs the LLM to act as a senior recruiter who values **potential over pedigree** — meaning a self-taught developer with strong projects can outscore a degree-holder with weak experience.

**Score Ranges:**

| Range | Label | Action |
|:---:|:---:|:---|
| 80-100 | 🏆 Exceptional | Immediate interview fast-track |
| 60-79 | ⭐ Strong | Flagged for priority review |
| 45-59 | 💡 Promising | Manual HR evaluation required |
| 0-44 | 📝 Below Bar | Constructive feedback email |

</details>

<br>

<details>
<summary><b>&nbsp;🌐&nbsp; Smart Phone Validation System</b></summary>

<br>

HireFlow implements **country-aware phone validation** supporting 8+ regions with strict digit-length enforcement:

```typescript
const COUNTRY_CONFIG = [
  { code: "+91",  label: "IN (+91)",   maxLength: 10 },  // India
  { code: "+1",   label: "US/CA (+1)", maxLength: 10 },  // North America
  { code: "+44",  label: "UK (+44)",   maxLength: 10 },  // United Kingdom
  { code: "+61",  label: "AU (+61)",   maxLength: 9  },  // Australia
  { code: "+971", label: "UAE (+971)", maxLength: 9  },  // UAE
  { code: "+49",  label: "DE (+49)",   maxLength: 11 },  // Germany
  { code: "+33",  label: "FR (+33)",   maxLength: 9  },  // France
  { code: "+81",  label: "JP (+81)",   maxLength: 10 },  // Japan
];
```

The input dynamically adapts:
- ✅ Placeholder text changes per country
- ✅ Max digit limit enforced in real-time
- ✅ Non-numeric characters blocked at input level
- ✅ Phone field resets on country change

</details>

<br>

<details>
<summary><b>&nbsp;📄&nbsp; Universal Resume Parser</b></summary>

<br>

```
                    ┌─────────────────┐
                    │  Resume Upload  │
                    │  (PDF or Image) │
                    └────────┬────────┘
                             │
                    ┌────────▼────────┐
                    │  Type Detection │
                    │  MIME Analysis  │
                    └───┬─────────┬───┘
                        │         │
              ┌─────────▼───┐ ┌───▼─────────┐
              │  PDF Engine │ │ OCR Engine  │
              │             │ │             │
              │  • Native   │ │ • Gemini    │
              │    extract  │ │   Vision    │
              │  • Max 5MB  │ │ • Max 1MB   │
              │  • Instant  │ │ • AI-based  │
              └─────────┬───┘ └───┬─────────┘
                        │         │
                    ┌───▼─────────▼───┐
                    │  Unified Text   │
                    │  → LLM Scoring  │
                    └─────────────────┘
```

**Supported Formats:**
- 📑 PDF documents (up to 5MB)
- 🖼️ JPG/JPEG images (up to 1MB)
- 🖼️ PNG images (up to 1MB)
- 📷 Scanned documents (via OCR)

</details>

<br>

<details>
<summary><b>&nbsp;🎨&nbsp; The 3D Experience Layer</b></summary>

<br>

The candidate portal isn't just a form — it's a **spatial experience**:

| Element | Technology | Effect |
|:---|:---|:---|
| Background Scene | Spline 3D + WebGL | Living, interactive 3D environment |
| Spotlight Effect | Custom SVG + CSS | Dynamic cursor-following light |
| Card Design | CSS Backdrop Blur | Glassmorphic floating interface |
| Submission | Canvas Confetti | GPU-accelerated particle celebration |
| Transitions | Framer Motion | Physics-based spring animations |
| Drag & Drop | React DnD Events | Glowing upload zone with haptic feedback |

The Spline scene loads asynchronously and renders at **60fps** using hardware-accelerated WebGL, ensuring the 3D experience doesn't compromise form usability.

</details>
